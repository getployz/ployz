# Domain docs

This repository has Engine and Cloud domain contexts.

Before exploring or changing the system:

- Read [CONTEXT-MAP.md](../../CONTEXT-MAP.md), then the relevant glossary. Read both
  glossaries for work crossing the Engine–Cloud boundary.
- Read relevant ADRs under `docs/adr/`.
- Use the glossary's defined terms rather than introducing synonyms.
- Surface conflicts with existing ADRs explicitly.
- Create or amend domain documentation only when a term or decision is actually resolved.
