# Hosted Beta Acceptance

Hosted beta acceptance is not defined for the current coreless v2 workspace.
The CLI, HTTP API, install path, mesh, deployment, gateway, DNS, and
certificate slices must first expose their stable public seams and focused
verification.

A future beta checklist belongs here only after those slices land. It must
name one sealed candidate, distinguish automated from manual proof, exercise
failure and retry evidence, cover every supported architecture, and link each
claim to the narrowest harness that actually proves it. A deleted incumbent
transport or authority path is never acceptable substitute evidence for v2.
