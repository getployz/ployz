# Organization enrollment uses one versioned Founding Claim

Cloud coordinates one Organization-scoped Founding Claim and protocol version 2 is a clean compatibility break, so an obsolete CLI cannot Initialize through the prior token-scoped flow. Founder completion is the final Cloud commit only after requested ingress and DNS converge, Cloud Pairing is published, and Relay holds the reported Machine under the current Pairing Credential; failures resume that founder or require an explicit verified reset rather than automatic transfer.
