# Organization enrollment uses one versioned Founding Claim

Cloud coordinates one Organization-scoped Founding Claim and protocol version 2 is a clean compatibility break, so an obsolete CLI cannot Initialize through the prior token-scoped flow. Founder completion is the final Cloud commit only after requested ingress and DNS converge, a protected Connection Candidate is persisted against the current claim, and shared Machine RPC negotiation verifies the intended Machine; failures resume that founder or require an explicit verified reset rather than automatic transfer. [0005](0005-tailcat-connection-candidates.md) supersedes the earlier relay-hold completion condition.
