The docs site generates agent-readable text from the Markdown docs.

- `/llms.txt` is a short index and command-safety note.
- `/llms-full.txt` is a full generated bundle.

Do not edit generated output by hand. Update the Markdown files under
`src/content/docs`, then rebuild the site.
