Guides are task-shaped. They should describe operator intent, not internal
module boundaries.

Every guide should include:

1. Preconditions.
2. The command to run.
3. The expected result.
4. Verification.
5. Recovery or retry guidance.

Start with current commands. Use north-star primitive names only when the guide
is explicitly describing product direction.
