# ployz project outputs (local SQLite Store)

Generated by store/run.sh against `PLOYZ_STORE=sqlite:...`, isolated HOME. Each block: pipe run (stdout/stderr split); `project.ansi` holds the TTY rerun.

### project ls (empty Store)

```console
$ ployz project ls
# exit 0
```

stdout:
```
No Projects yet. Create one: ployz project new NAME
```

### project ls --json (empty Store)

```console
$ ployz --json project ls
# exit 0
```

stdout:
```
{
  "projects": []
}
```
