# ployz service outputs (local SQLite Store)

Generated by store/run.sh against `PLOYZ_STORE=sqlite:...`, isolated HOME. Each block: pipe run (stdout/stderr split); `service.ansi` holds the TTY rerun.

### service ls (no Services)

```console
$ ployz service ls
# exit 0
```

stdout:
```
SERVICE	PRIVATE DNS	SOURCE	NEXT DEPLOY
```

stderr:
```
No Services in production yet.
next: ployz service add NAME --image REF --project shop
```

### service add: --image and --repo together

```console
$ ployz service add api --image a:1 --repo acme/api
# exit 2
```

stderr:
```
error: the argument '--image <REF>' cannot be used with '--repo <OWNER/REPO[@BRANCH]>'

Usage: ployz service add --image <REF> --project <project> <name>

For more information, try '--help'.
```
