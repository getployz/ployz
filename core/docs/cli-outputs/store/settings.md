# ployz settings outputs (local SQLite Store)

Generated by store/run.sh against `PLOYZ_STORE=sqlite:...`, isolated HOME. Each block: pipe run (stdout/stderr split); `settings.ansi` holds the TTY rerun.

### get (no Services)

```console
$ ployz get
# exit 0
```

stdout:
```
No Services in shop/production.
```

